## 🚀 Featured Projects

### 🌾 CoopConnect
*Empowering Rwandan Farmers Through Digital Learning*

A digital platform that helps Rwandan farmers learn about agriculture through training sessions and gamified rewards. Farmers earn points for participation that can be redeemed for future training, making quality education more accessible and engaging.

**Tech Stack:** Python, Django, SQL, React  
**Impact:** Democratizing agricultural knowledge for smallholder farmers

---

### 🎨 CraftCrest
*Connecting Kenyan Artisans with the World*

A mobile and web platform that connects Kenyan artisans directly with buyers globally. Features include product showcasing, custom order management, and secure payment holding until buyer confirmation—creating a trustworthy marketplace for local craftsmanship.

**Tech Stack:** TypeScript, NextJS, React, MongoDB  
**Impact:** Supporting local artisans and enabling e-commerce access
